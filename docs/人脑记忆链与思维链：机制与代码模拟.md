# 第一部分：人脑记忆机制与代码模拟

## 1.1 人脑记忆链的核心机制

人脑记忆不是把一段经历像文件一样存进某个“抽屉”，而是：

| 机制 | 说明 | 类比 |
|---|---|---|
| **分布式多模态存储** | 视觉、听觉、语义、情绪、动作片段分散存储在不同皮层网络 | 数据分片存储 |
| **海马索引绑定** | 海马把分散片段绑定成可提取的“情景索引” | 数据库索引/外键 |
| **模式完成** | 一个线索（如气味）能激活整条记忆路径 | 键值查询触发整条记录 |
| **模式分离** | 相似经历被区分开，避免混淆 | 去重/哈希区分 |
| **序列重放** | 睡眠/休息时海马-皮层重放事件序列，巩固连接 | 离线训练/回放 |
| **再巩固** | 每次提取都会使记忆不稳定化再稳定，可能被修改 | 读时重写 |
| **提取即重构** | 回忆不是只读，而是按当前目标、情绪、图式重建 | 查询时动态拼装 |
| **前额叶控制** | 决定检索什么、抑制什么、按什么顺序组织 | 查询优化器 |

### 记忆链的常见类型

| 类型 | 连接方式 | 例子 |
|---|---|---|
| 情景链 | 时间、地点、人物 | 早上出门→下雨→忘带伞 |
| 因果链 | 原因—结果 | 迟到→被批评 |
| 语义链 | 上下位、属性、同义 | 狗→动物→哺乳动物 |
| 空间链 | 路线、邻接、地标 | 回家路上的建筑序列 |
| 程序链 | 动作步骤、顺序依赖 | 骑车、打字、做饭 |
| 情绪链 | 情绪相似、威胁/奖赏标记 | 闻到气味想起某段经历 |
| 自传体叙事链 | 自我连续性、人生阶段 | “我小时候……后来……” |

## 1.2 记忆网络核心代码

以下代码模拟：**节点 + 多种关系边 + 海马索引 + 激活扩散 + 模式完成 + 序列重放 + 再巩固 + 遗忘**。

```python
# ===== 第一部分：人脑记忆网络模拟 =====
from collections import defaultdict, deque
import random

class Node:
    def __init__(self, nid, content, modality="concept", emotion=0.0):
        self.nid = nid
        self.content = content
        self.modality = modality   # concept / episode / sensory / action / emotion
        self.emotion = emotion     # 情绪标记 -1..1
        self.activation = 0.0

class Edge:
    def __init__(self, src, dst, rel, weight=1.0):
        self.src, self.dst = src, dst
        self.rel = rel             # causal / temporal / semantic / spatial / emotional / procedural
        self.weight = weight

class MemoryNetwork:
    """分布式记忆网络 + 海马索引"""
    def __init__(self):
        self.nodes = {}
        self.edges = defaultdict(list)   # 邻接表：分布式网络
        self.hippocampus = {}            # 海马索引：情景名 -> 片段序列

    def add_node(self, node):
        self.nodes[node.nid] = node

    def add_edge(self, src, dst, rel, weight=1.0, bidirectional=True):
        self.edges[src].append(Edge(src, dst, rel, weight))
        if bidirectional:
            self.edges[dst].append(Edge(dst, src, rel, weight))

    def bind_episode(self, name, nids):
        """海马索引：把分散片段绑定成一个可提取情景"""
        self.hippocampus[name] = list(nids)

    # ---------- 并行激活扩散 ----------
    def spread(self, seeds, steps=3, decay=0.65):
        act = defaultdict(float)
        for s in seeds:
            act[s] = 1.0
        frontier = deque(seeds)
        for _ in range(steps):
            nxt = deque()
            for nid in frontier:
                for e in self.edges[nid]:
                    gain = act[nid] * e.weight * decay
                    if gain > act[e.dst] + 1e-6:
                        act[e.dst] = gain
                        nxt.append(e.dst)
            frontier = nxt
        return act

    # ---------- 模式完成：线索触发整条记忆链 ----------
    def recall(self, cue, episode, steps=4, decay=0.7):
        act = self.spread([cue], steps=steps, decay=decay)
        bound = set(self.hippocampus.get(episode, []))
        return sorted(
            ((n, round(a, 3)) for n, a in act.items() if n in bound),
            key=lambda x: -x[1]
        )

    # ---------- 序列重放：巩固相邻连接 ----------
    def replay(self, episode, cycles=3, lr=1.1):
        seq = self.hippocampus[episode]
        for _ in range(cycles):
            for a, b in zip(seq, seq[1:]):
                for e in self.edges[a]:
                    if e.dst == b:
                        e.weight *= lr

    # ---------- 再巩固：提取时重构记忆顺序 ----------
    def reconsolidate(self, episode, new_order):
        self.hippocampus[episode] = list(new_order)

    # ---------- 遗忘：随机削弱部分连接 ----------
    def forget(self, episode, drop_ratio=0.2, decay=0.5):
        seq = self.hippocampus[episode]
        for a, b in zip(seq, seq[1:]):
            if random.random() < drop_ratio:
                for e in self.edges[a]:
                    if e.dst == b:
                        e.weight *= decay

# ---------- 演示 ----------
def demo_memory():
    m = MemoryNetwork()
    for nid, c, mod, emo in [
        ("wake", "起床", "episode", 0.1),
        ("rain", "下雨", "sensory", -0.3),
        ("forget", "忘带伞", "action", -0.5),
        ("late", "迟到", "episode", -0.6),
        ("criticized", "被批评", "emotion", -0.8),
        ("umbrella", "伞", "concept", 0.0),
    ]:
        m.add_node(Node(nid, c, mod, emo))

    for a, b, r, w in [
        ("wake", "rain", "temporal", 1.0),
        ("rain", "forget", "causal", 0.9),
        ("forget", "late", "causal", 0.8),
        ("late", "criticized", "causal", 0.9),
        ("rain", "umbrella", "semantic", 1.0),
        ("forget", "umbrella", "semantic", 0.7),
    ]:
        m.add_edge(a, b, r, w)

    m.bind_episode("bad_morning", ["wake", "rain", "forget", "late", "criticized"])

    print("【模式完成】线索=伞 →", m.recall("umbrella", "bad_morning"))
    print("【模式完成】线索=起床 →", m.recall("wake", "bad_morning"))

    m.replay("bad_morning", cycles=2)
    print("【重放后】wake→rain 权重 =",
          [e.weight for e in m.edges["wake"] if e.dst == "rain"][0])

    m.reconsolidate("bad_morning", ["wake", "rain", "late", "forget", "criticized"])
    print("【再巩固后情景】", m.hippocampus["bad_morning"])

if __name__ == "__main__":
    demo_memory()
```

**代码与脑机制对照**

| 代码 | 脑机制 |
|---|---|
| `nodes + edges` | 分布式多模态记忆网络 |
| `rel` 多种关系 | 因果、时序、语义、空间、情绪、程序边 |
| `spread()` | 并行激活扩散 |
| `bind_episode()` | 海马索引绑定 |
| `recall()` | 模式完成：一个线索激活整条链 |
| `replay()` | 睡眠/休息时序列重放巩固 |
| `reconsolidate()` | 提取时重构记忆 |
| `forget()` | 遗忘与连接削弱 |

# 第二部分：人脑思维链模式与代码模拟

## 2.1 人脑思维链的核心机制

人脑思维链不是一串显式文字步骤，而是：

**分布式并行加工 → 注意选择 → 工作记忆维持 → 逐步操作 → 元认知检查 → 语言/叙事压缩。**

| 机制 | 说明 |
|---|---|
| **双系统** | 系统1快速直觉、并行；系统2慢速受控、串行 |
| **全局工作空间** | 大量并行加工中只有一部分被“广播”，形成可体验的序列 |
| **工作记忆瓶颈** | 容量约 4 个组块，迫使思维串行化 |
| **预测加工** | 大脑不断预测下一步，用误差修正内部模型 |
| **元认知监控** | 检查、纠错、置信评估、策略切换 |
| **语言压缩** | 内部言语把复杂过程压缩成“句子链”用于报告 |

### 思维链中的关系类型

| 关系类型 | 具体关系 | 例子 |
|---|---|---|
| 逻辑关系 | 蕴含、等价、矛盾、排他 | A 推出 B |
| 因果/解释 | 原因—结果、机制解释 | 电压升高→电流增大 |
| 条件与规则 | 充分/必要、如果—那么 | 若 x>0，则…… |
| 证据—结论 | 支持、例证、削弱、反驳 | 数据支持假设 |
| 问题分解 | 整体—部分、目标—子目标 | 先求 A，再求 B |
| 比较与分类 | 相同/差异、类比、归类 | A 与 B 类似 |
| 时序与过程 | 先后、并行、循环、反馈 | 初始化→迭代→收敛 |
| 数量与计算 | 等式、不等式、函数依赖 | 代入公式得…… |
| 假设—检验 | 假设—预测—验证—修正 | 若假设成立，应观察到…… |
| 元认知 | 检查、纠错、置信评估 | 这一步可能出错，回头验证 |

## 2.2 思维链核心代码

以下代码模拟：**思维图 + 工作记忆瓶颈 + 启发式选择 + 串行轨迹 + 元认知检查**。

```python
# ===== 第二部分：人脑思维链模拟 =====
from collections import defaultdict

class ThoughtGraph:
    """思维关系图：节点是命题/子目标，边是推理关系"""
    def __init__(self):
        self.adj = defaultdict(list)   # nid -> [(dst, rel, weight)]

    def add(self, a, b, rel, w=1.0):
        self.adj[a].append((b, rel, w))

    def neighbors(self, nid):
        return self.adj.get(nid, [])

class WorkingMemory:
    """工作记忆：容量瓶颈 + 串行轨迹"""
    def __init__(self, capacity=4):
        self.capacity = capacity
        self.slots = []
        self.trace = []                # 主观“思维链”

    def attend(self, scored):
        """注意选择：只保留激活最高的若干项"""
        ranked = sorted(scored, key=lambda x: -x[1])
        self.slots = [n for n, _ in ranked[:self.capacity]]
        return self.slots

    def record(self, prev, rel, cur, note=""):
        self.trace.append({"from": prev, "rel": rel, "to": cur, "note": note})

class Reasoner:
    """目标导向的串行推理器"""
    def __init__(self, graph, wm, goal=None):
        self.g, self.wm, self.goal = graph, wm, goal

    def score(self, cand):
        nxt, rel, w = cand
        s = w
        if rel in ("causal", "temporal", "implies"):
            s *= 2                      # 因果/时序/蕴含优先
        if self.goal and nxt == self.goal:
            s += 10                     # 目标启发
        return s

    def metacog_check(self, path):
        """元认知：检查循环与路径长度"""
        if len(path) != len(set(path)):
            return False, "检测到循环"
        if len(path) > 8:
            return False, "路径过长"
        return True, "ok"

    def think(self, start, goal, max_steps=8):
        self.goal = goal
        path, cur = [start], start
        for _ in range(max_steps):
            if cur == goal:
                break
            cands = self.g.neighbors(cur)
            if not cands:
                self.wm.record(cur, "dead_end", None, "无可用后继")
                break
            scored = [(nxt, self.score((nxt, rel, w))) for nxt, rel, w in cands]
            chosen = self.wm.attend(scored)[0]       # 注意瓶颈选出
            rel = next(r for n, r, w in cands if n == chosen)
            self.wm.record(cur, rel, chosen)
            path.append(chosen)
            cur = chosen
            ok, msg = self.metacog_check(path)
            if not ok:
                self.wm.record(cur, "metacog_stop", None, msg)
                break
        return path

# ---------- 演示 ----------
def demo_thought():
    g = ThoughtGraph()
    for a, b, r, w in [
        ("起床", "下雨", "temporal", 1.0),
        ("下雨", "忘带伞", "causal", 0.9),
        ("忘带伞", "迟到", "causal", 0.8),
        ("迟到", "被批评", "causal", 0.9),
        ("下雨", "带伞", "causal", 0.95),
        ("带伞", "不迟到", "causal", 0.9),
        ("不迟到", "不被批评", "causal", 0.9),
    ]:
        g.add(a, b, r, w)

    wm = WorkingMemory(capacity=3)
    r = Reasoner(g, wm)
    path = r.think("起床", "不被批评")
    print("【思维链路径】", path)
    print("【串行轨迹】")
    for step in wm.trace:
        print("  ", step)

if __name__ == "__main__":
    demo_thought()
```

**代码与脑机制对照**

| 代码 | 脑机制 |
|---|---|
| `ThoughtGraph` | 命题/子目标之间的推理关系网络 |
| `WorkingMemory.capacity` | 工作记忆容量瓶颈（约 4 组块） |
| `attend()` | 注意选择，把并行激活压缩成少数候选 |
| `trace` | 主观可体验的串行“思维链” |
| `score()` | 系统1启发式 + 系统2规则加权 |
| `metacog_check()` | 元认知监控与纠错 |

# 第三部分：思维链与记忆链相互调用机制与代码模拟

## 3.1 相互调用机制

记忆链和思维链不是两条独立管线，而是持续互相调用：

```
        ┌──────────────┐
        │   记忆网络    │
        │ (分布式+海马) │
        └──────┬───────┘
               │ ① 检索：线索激活相关记忆
               ▼
        ┌──────────────┐
        │   工作记忆    │  ← 注意瓶颈
        └──────┬───────┘
               │ ② 推理：在候选上做目标导向选择
               ▼
        ┌──────────────┐
        │   思维链      │
        │ 逐步串行推进  │
        └──────┬───────┘
               │ ③ 验证：元认知检查
               ▼
        ┌──────────────┐
        │  写回/再巩固  │
        │ 新结论→新记忆 │
        └──────┬───────┘
               │ ④ 重放巩固
               └──────────► 回到记忆网络
```

| 方向 | 机制 | 说明 |
|---|---|---|
| **记忆 → 思维** | 检索提供前提、类比、情景模拟 | 推理需要素材 |
| **思维 → 记忆** | 推理结论写入新情景 | 学习与知识更新 |
| **情绪加权** | 情绪标记影响检索优先级与候选评分 | 重要/威胁相关记忆优先被唤醒 |
| **元认知控制** | 决定何时检索、检索什么、何时停止 | 策略性搜索 |
| **再巩固** | 推理改变记忆顺序和连接权重 | 记忆因思考而改写 |
| **互补学习系统** | 海马快速编码情景，皮层慢速整合统计规律 | 快慢双系统 |

## 3.2 整合代码：CognitiveAgent

以下代码整合前两部分，实现完整的 **检索 → 推理 → 验证 → 写回 → 重放** 循环。  
> 依赖第一部分的 `MemoryNetwork`、`Node`、`Edge` 和第二部分的 `WorkingMemory`、`ThoughtGraph`、`Reasoner`。为便于独立运行，附录给出合并后的完整脚本。

```python
# ===== 第三部分：思维链与记忆链相互调用 =====
class CognitiveAgent:
    def __init__(self, memory, capacity=4):
        self.mem = memory
        self.wm = WorkingMemory(capacity)
        self.reasoner = Reasoner(ThoughtGraph(), self.wm)
        # 从记忆网络构建思维图：记忆中的边成为推理可用关系
        for src, es in memory.edges.items():
            for e in es:
                self.reasoner.g.add(src, e.dst, e.rel, e.weight)
        self.new_memories = []

    # ---------- ① 检索：用当前节点作线索唤醒记忆 ----------
    def retrieve(self, cue, topk=3):
        act = self.mem.spread([cue], steps=3, decay=0.65)
        return sorted(act.items(), key=lambda x: -x[1])[:topk]

    # ---------- ② 推理 + ③ 验证 + ④ 写回 ----------
    def think_with_memory(self, start, goal, max_steps=8):
        path, cur = [start], start
        self.wm.trace = []
        for _ in range(max_steps):
            if cur == goal:
                break

            # ① 检索：记忆链为思维链提供候选与加权
            retrieved = self.retrieve(cur, topk=3)
            retrieved_dict = dict(retrieved)

            # ② 推理：图邻居 + 记忆激活加成
            cands = self.reasoner.g.neighbors(cur)
            scored = []
            for nxt, rel, w in cands:
                s = w * (2 if rel in ("causal", "temporal", "implies") else 1)
                s += retrieved_dict.get(nxt, 0)      # 记忆激活加成
                if nxt == goal:
                    s += 10
                scored.append((nxt, s, rel))

            if not scored:
                self.wm.record(cur, "dead_end", None, "无可用后继")
                break

            scored.sort(key=lambda x: -x[1])
            chosen, _, rel = scored[0]
            self.wm.record(cur, rel, chosen, f"retrieved={retrieved}")
            path.append(chosen)
            cur = chosen

            # ③ 元认知验证
            ok, msg = self.reasoner.metacog_check(path)
            if not ok:
                self.wm.record(cur, "metacog_stop", None, msg)
                break

        # ④ 写回 + 重放巩固：思维结果成为新记忆
        self.learn_from_thought(path)
        return path

    # ---------- 思维 → 记忆：写回与巩固 ----------
    def learn_from_thought(self, path, name=None):
        name = name or f"thought_{len(self.new_memories)}"
        self.mem.bind_episode(name, path)            # 海马索引新情景
        self.mem.replay(name, cycles=2)              # 序列重放巩固
        # 把推理出的新边加入思维图与记忆网络
        for a, b in zip(path, path[1:]):
            self.reasoner.g.add(a, b, "inferred", 0.8)
            self.mem.add_edge(a, b, "inferred", 0.8, bidirectional=False)
        self.new_memories.append(name)
        return name

# ---------- 演示 ----------
def demo_agent():
    # 构造记忆网络（复用第一部分结构）
    m = MemoryNetwork()
    for nid, c in [
        ("起床", "起床"), ("下雨", "下雨"), ("忘带伞", "忘带伞"),
        ("迟到", "迟到"), ("被批评", "被批评"),
        ("带伞", "带伞"), ("不迟到", "不迟到"), ("不被批评", "不被批评"),
    ]:
        m.add_node(Node(nid, c))

    for a, b, r, w in [
        ("起床", "下雨", "temporal", 1.0),
        ("下雨", "忘带伞", "causal", 0.9),
        ("忘带伞", "迟到", "causal", 0.8),
        ("迟到", "被批评", "causal", 0.9),
        ("下雨", "带伞", "causal", 0.95),
        ("带伞", "不迟到", "causal", 0.9),
        ("不迟到", "不被批评", "causal", 0.9),
    ]:
        m.add_edge(a, b, r, w)

    m.bind_episode("bad_morning", ["起床", "下雨", "忘带伞", "迟到", "被批评"])

    agent = CognitiveAgent(m)
    path = agent.think_with_memory("起床", "不被批评")

    print("【整合思维链】", path)
    print("\n【每步检索与选择】")
    for step in agent.wm.trace:
        print("  ", step)

    print("\n【写回的新记忆】", agent.new_memories)
    print("【新情景内容】", m.hippocampus[agent.new_memories[0]])
    print("【新边 weight】",
          [e.weight for e in m.edges["带伞"] if e.dst == "不迟到"])
```

```python
# ===== 完整脚本：brain_sim.py =====
from collections import defaultdict, deque
import random

# ---------- 公共基础 ----------
class Node:
    def __init__(self, nid, content, modality="concept", emotion=0.0):
        self.nid, self.content = nid, content
        self.modality, self.emotion = modality, emotion
        self.activation = 0.0

class Edge:
    def __init__(self, src, dst, rel, weight=1.0):
        self.src, self.dst, self.rel, self.weight = src, dst, rel, weight

class MemoryNetwork:
    def __init__(self):
        self.nodes = {}
        self.edges = defaultdict(list)
        self.hippocampus = {}

    def add_node(self, node):
        self.nodes[node.nid] = node

    def add_edge(self, src, dst, rel, weight=1.0, bidirectional=True):
        self.edges[src].append(Edge(src, dst, rel, weight))
        if bidirectional:
            self.edges[dst].append(Edge(dst, src, rel, weight))

    def bind_episode(self, name, nids):
        self.hippocampus[name] = list(nids)

    def spread(self, seeds, steps=3, decay=0.65):
        act = defaultdict(float)
        for s in seeds:
            act[s] = 1.0
        frontier = deque(seeds)
        for _ in range(steps):
            nxt = deque()
            for nid in frontier:
                for e in self.edges[nid]:
                    gain = act[nid] * e.weight * decay
                    if gain > act[e.dst] + 1e-6:
                        act[e.dst] = gain
                        nxt.append(e.dst)
            frontier = nxt
        return act

    def recall(self, cue, episode, steps=4, decay=0.7):
        act = self.spread([cue], steps=steps, decay=decay)
        bound = set(self.hippocampus.get(episode, []))
        return sorted(((n, round(a, 3)) for n, a in act.items() if n in bound),
                      key=lambda x: -x[1])

    def replay(self, episode, cycles=3, lr=1.1):
        seq = self.hippocampus[episode]
        for _ in range(cycles):
            for a, b in zip(seq, seq[1:]):
                for e in self.edges[a]:
                    if e.dst == b:
                        e.weight *= lr

    def reconsolidate(self, episode, new_order):
        self.hippocampus[episode] = list(new_order)

    def forget(self, episode, drop_ratio=0.2, decay=0.5):
        seq = self.hippocampus[episode]
        for a, b in zip(seq, seq[1:]):
            if random.random() < drop_ratio:
                for e in self.edges[a]:
                    if e.dst == b:
                        e.weight *= decay

class ThoughtGraph:
    def __init__(self):
        self.adj = defaultdict(list)
    def add(self, a, b, rel, w=1.0):
        self.adj[a].append((b, rel, w))
    def neighbors(self, nid):
        return self.adj.get(nid, [])

class WorkingMemory:
    def __init__(self, capacity=4):
        self.capacity = capacity
        self.slots, self.trace = [], []
    def attend(self, scored):
        ranked = sorted(scored, key=lambda x: -x[1])
        self.slots = [n for n, _ in ranked[:self.capacity]]
        return self.slots
    def record(self, prev, rel, cur, note=""):
        self.trace.append({"from": prev, "rel": rel, "to": cur, "note": note})

class Reasoner:
    def __init__(self, graph, wm, goal=None):
        self.g, self.wm, self.goal = graph, wm, goal
    def score(self, cand):
        nxt, rel, w = cand
        s = w * (2 if rel in ("causal", "temporal", "implies") else 1)
        if self.goal and nxt == self.goal:
            s += 10
        return s
    def metacog_check(self, path):
        if len(path) != len(set(path)):
            return False, "检测到循环"
        if len(path) > 8:
            return False, "路径过长"
        return True, "ok"
    def think(self, start, goal, max_steps=8):
        self.goal = goal
        path, cur = [start], start
        for _ in range(max_steps):
            if cur == goal:
                break
            cands = self.g.neighbors(cur)
            if not cands:
                self.wm.record(cur, "dead_end", None, "无可用后继")
                break
            scored = [(nxt, self.score((nxt, rel, w))) for nxt, rel, w in cands]
            chosen = self.wm.attend(scored)[0]
            rel = next(r for n, r, w in cands if n == chosen)
            self.wm.record(cur, rel, chosen)
            path.append(chosen)
            cur = chosen
            ok, msg = self.metacog_check(path)
            if not ok:
                self.wm.record(cur, "metacog_stop", None, msg)
                break
        return path

class CognitiveAgent:
    def __init__(self, memory, capacity=4):
        self.mem = memory
        self.wm = WorkingMemory(capacity)
        self.reasoner = Reasoner(ThoughtGraph(), self.wm)
        for src, es in memory.edges.items():
            for e in es:
                self.reasoner.g.add(src, e.dst, e.rel, e.weight)
        self.new_memories = []

    def retrieve(self, cue, topk=3):
        act = self.mem.spread([cue], steps=3, decay=0.65)
        return sorted(act.items(), key=lambda x: -x[1])[:topk]

    def think_with_memory(self, start, goal, max_steps=8):
        path, cur = [start], start
        self.wm.trace = []
        for _ in range(max_steps):
            if cur == goal:
                break
            retrieved = self.retrieve(cur, topk=3)
            rd = dict(retrieved)
            cands = self.reasoner.g.neighbors(cur)
            scored = []
            for nxt, rel, w in cands:
                s = w * (2 if rel in ("causal", "temporal", "implies") else 1)
                s += rd.get(nxt, 0)
                if nxt == goal:
                    s += 10
                scored.append((nxt, s, rel))
            if not scored:
                self.wm.record(cur, "dead_end", None, "无可用后继")
                break
            scored.sort(key=lambda x: -x[1])
            chosen, _, rel = scored[0]
            self.wm.record(cur, rel, chosen, f"retrieved={retrieved}")
            path.append(chosen)
            cur = chosen
            ok, msg = self.reasoner.metacog_check(path)
            if not ok:
                self.wm.record(cur, "metacog_stop", None, msg)
                break
        self.learn_from_thought(path)
        return path

    def learn_from_thought(self, path, name=None):
        name = name or f"thought_{len(self.new_memories)}"
        self.mem.bind_episode(name, path)
        self.mem.replay(name, cycles=2)
        for a, b in zip(path, path[1:]):
            self.reasoner.g.add(a, b, "inferred", 0.8)
            self.mem.add_edge(a, b, "inferred", 0.8, bidirectional=False)
        self.new_memories.append(name)
        return name
```

## 结语

这套模拟只抓住了骨架：**网络 → 激活 → 瓶颈 → 串行链 → 重放/重构 → 写回**。它与真实人脑的差距在于：真实系统是连续神经动力学、多模态感知、情绪与身体状态深度耦合的；而这里用离散节点和简化启发式近似。但作为理解“记忆链与思维链如何相互调用”的教学模型，它已经能清晰展示核心回路：

> **记忆为思维提供素材，思维为记忆写入新结构；每一次回忆都在重构，每一次推理都在学习。**
