情绪在三个层面起作用：

| 层面 | 作用 | 例子 |
|---|---|---|
| **记忆** | 情绪唤醒增强编码；情绪一致性提取；情绪作检索线索 | 被批评的场景记得更牢；焦虑时更容易想起糟心事 |
| **思维** | 调制候选权重；切换加工模式；占用工作记忆 | 焦虑偏向威胁线索；积极情绪促进启发式 |
| **决策** | 提供价值信号；预期情绪引导选择 | 预期后悔让人回避风险；躯体标记引导直觉判断 |

## 2. 核心机制

### 2.1 情绪的二维表示

用 **效价（valence，-1 到 +1）** 和 **唤醒度（arousal，0 到 1）** 描述情绪状态：

| 维度 | 含义 | 低 | 高 |
|---|---|---|---|
| 效价 | 愉快—不愉快 | 悲伤、厌恶 | 喜悦、满足 |
| 唤醒 | 平静—激动 | 放松、疲倦 | 愤怒、恐惧、兴奋 |

### 2.2 情绪对记忆的调制

| 机制 | 说明 | 代码落点 |
|---|---|---|
| **情绪增强巩固** | 高唤醒事件经杏仁核调节海马，记忆更强 | `consolidation_gain()` 提高 replay 学习率 |
| **情绪一致性提取** | 当前情绪偏向提取同效价记忆 | `retrieval_bias()` 按效价匹配加成 |
| **情绪作线索** | 情绪状态本身可激活相关记忆 | 把情绪状态作为扩散种子 |
| **闪光灯记忆** | 高唤醒事件记忆更生动（未必更准） | 高唤醒节点激活增益更大 |

### 2.3 情绪对思维的调制

| 机制 | 说明 | 代码落点 |
|---|---|---|
| **威胁偏向** | 负效价高唤醒时，威胁/损失相关候选加权 | `reasoning_bias()` |
| **奖赏偏向** | 正效价时，奖赏相关候选加权 | `reasoning_bias()` |
| **加工模式切换** | 积极→启发式/全局；消极→系统化/细节 | `mode_switch()` |
| **工作记忆占用** | 高焦虑占用资源，有效容量下降 | `wm_capacity_penalty()` |
| **预期情绪** | 对结果的情绪预期影响选择 | 候选评分中加入预期效价 |

### 2.4 情绪调节

| 策略 | 说明 | 代码落点 |
|---|---|---|
| **重评** | 改变对事件意义的解释，降低唤醒 | `regulate("reappraise")` |
| **抑制** | 压低情绪表达/强度 | `regulate("suppress")` |
| **转移注意** | 把注意移开情绪源 | `regulate("distract")` |
| **自然衰减** | 情绪随时间回落到基线 | `decay()` |

### 2.5 情绪与目标的耦合

情绪不是孤立状态，而是**对目标进展的评估信号**：

- 目标受阻 → 负效价 + 高唤醒（愤怒/焦虑）
- 目标推进 → 正效价（喜悦/满足）
- 目标受威胁 → 负效价 + 高唤醒（恐惧）
- 目标丧失 → 负效价 + 低唤醒（悲伤）

代码中用 `goal_progress` 驱动 `appraise()`。

## 3. 情绪模块代码

```python
# ===== 情绪/感情模块 =====
import math

class EmotionState:
    """二维情绪状态：效价 + 唤醒"""
    def __init__(self, valence=0.0, arousal=0.0):
        self.valence = max(-1.0, min(1.0, valence))   # -1..1
        self.arousal = max(0.0, min(1.0, arousal))    # 0..1

    def __repr__(self):
        return f"Emotion(v={self.valence:+.2f}, a={self.arousal:.2f})"

    def decay(self, rate=0.15):
        """情绪随时间回落到基线（中性、低唤醒）"""
        self.valence *= (1 - rate)
        self.arousal *= (1 - rate)

    def copy(self):
        return EmotionState(self.valence, self.arousal)


class EmotionModule:
    """情绪评估、调制、调节"""

    # ---------- 评估：事件 + 目标进展 → 情绪变化 ----------
    def appraise(self, event_emotion, goal_progress, current, sensitivity=0.6):
        """
        event_emotion: (valence, arousal) 事件本身的情绪色彩
        goal_progress: -1..1  目标受阻(-) 到 目标推进(+)
        current: 当前 EmotionState
        返回新的 EmotionState
        """
        ev, ea = event_emotion
        # 目标进展本身产生情绪
        goal_v = goal_progress * 0.5
        goal_a = abs(goal_progress) * 0.4
        # 事件情绪与目标情绪叠加，带敏感度
        new_v = current.valence + sensitivity * (ev + goal_v - current.valence)
        new_a = current.arousal + sensitivity * (ea + goal_a - current.arousal)
        return EmotionState(new_v, new_a)

    # ---------- 记忆提取偏向：情绪一致性 ----------
    def retrieval_bias(self, act, current, node_emotions, bias_strength=0.5):
        """
        act: {nid: 激活值}
        node_emotions: {nid: (valence, arousal)}
        当前情绪与节点情绪效价越一致，加成越大；高唤醒整体提升显著性
        """
        biased = {}
        for nid, a in act.items():
            ev, ea = node_emotions.get(nid, (0.0, 0.0))
            # 效价一致性：同号且接近 → 加成
            congruence = 1.0 - abs(current.valence - ev) / 2.0   # 0..1
            # 唤醒放大：当前唤醒越高，整体激活越强
            arousal_gain = 1.0 + current.arousal * 0.8
            # 高情绪节点本身更显著
            salience = 1.0 + ea * 0.5
            biased[nid] = a * (1 + bias_strength * congruence) * arousal_gain * salience
        return biased

    # ---------- 推理偏向：威胁/奖赏加权 + 加工模式 ----------
    def reasoning_bias(self, scored_cands, current, node_emotions):
        """
        scored_cands: [(nid, score, rel), ...]
        """
        mode = self.mode_switch(current)
        biased = []
        for nid, s, rel in scored_cands:
            ev, ea = node_emotions.get(nid, (0.0, 0.0))
            bonus = 0.0
            # 负效价高唤醒 → 威胁偏向：负性候选加权
            if current.valence < -0.2 and current.arousal > 0.4:
                bonus += max(0, -ev) * current.arousal * 1.2
            # 正效价 → 奖赏偏向：正性候选加权
            if current.valence > 0.2:
                bonus += max(0, ev) * current.valence * 0.8
            # 加工模式：分析模式更看重因果/规则边
            if mode == "analytic" and rel in ("causal", "implies", "temporal"):
                bonus += 0.4
            if mode == "heuristic" and rel in ("semantic", "assoc"):
                bonus += 0.3
            biased.append((nid, s + bonus, rel))
        return biased

    def mode_switch(self, current):
        """积极情绪→启发式/全局；消极情绪→系统化/分析"""
        if current.valence > 0.25:
            return "heuristic"
        if current.valence < -0.2:
            return "analytic"
        return "neutral"

    # ---------- 工作记忆容量惩罚 ----------
    def wm_capacity_penalty(self, current, base_capacity=4):
        """高唤醒负效价（焦虑/愤怒）占用工作记忆资源"""
        load = current.arousal * max(0, -current.valence)
        return max(2, base_capacity - int(round(load * 2)))

    # ---------- 情绪增强巩固 ----------
    def consolidation_gain(self, current, base_lr=1.1):
        """高唤醒增强记忆巩固（杏仁核调节海马）"""
        gain = 1.0 + current.arousal * 0.5
        return base_lr * gain

    # ---------- 情绪调节 ----------
    def regulate(self, current, strategy="reappraise"):
        if strategy == "reappraise":
            # 重评：改变解释，降低唤醒与负效价
            return EmotionState(current.valence * 0.7, current.arousal * 0.5)
        if strategy == "suppress":
            # 抑制：压低强度
            return EmotionState(current.valence * 0.8, current.arousal * 0.6)
        if strategy == "distract":
            # 转移注意：快速降低唤醒
            return EmotionState(current.valence * 0.9, current.arousal * 0.4)
        return current.copy()
```

## 4. 接入 CognitiveAgent 的整合代码

下面把情绪模块接入前文第三部分的 `CognitiveAgent`。为便于独立运行，包含必要的记忆/思维类（精简版）。

```python
# ===== 完整整合：记忆 + 思维 + 情绪 =====
from collections import defaultdict, deque

class Node:
    def __init__(self, nid, content, emotion=(0.0, 0.0)):
        self.nid, self.content = nid, content
        self.emotion = emotion   # (valence, arousal) 情绪标记

class Edge:
    def __init__(self, src, dst, rel, weight=1.0):
        self.src, self.dst, self.rel, self.weight = src, dst, rel, weight

class MemoryNetwork:
    def __init__(self):
        self.nodes, self.edges, self.hippocampus = {}, defaultdict(list), {}

    def add_node(self, node):
        self.nodes[node.nid] = node

    def add_edge(self, src, dst, rel, weight=1.0, bidirectional=True):
        self.edges[src].append(Edge(src, dst, rel, weight))
        if bidirectional:
            self.edges[dst].append(Edge(dst, src, rel, weight))

    def bind_episode(self, name, nids):
        self.hippocampus[name] = list(nids)

    def spread(self, seeds, steps=3, decay=0.65):
        act = defaultdict(float)
        for s in seeds:
            act[s] = 1.0
        frontier = deque(seeds)
        for _ in range(steps):
            nxt = deque()
            for nid in frontier:
                for e in self.edges[nid]:
                    gain = act[nid] * e.weight * decay
                    if gain > act[e.dst] + 1e-6:
                        act[e.dst] = gain
                        nxt.append(e.dst)
            frontier = nxt
        return act

    def replay(self, episode, cycles=3, lr=1.1):
        seq = self.hippocampus[episode]
        for _ in range(cycles):
            for a, b in zip(seq, seq[1:]):
                for e in self.edges[a]:
                    if e.dst == b:
                        e.weight *= lr

    def node_emotions(self):
        return {nid: n.emotion for nid, n in self.nodes.items()}


class ThoughtGraph:
    def __init__(self):
        self.adj = defaultdict(list)
    def add(self, a, b, rel, w=1.0):
        self.adj[a].append((b, rel, w))
    def neighbors(self, nid):
        return self.adj.get(nid, [])


class WorkingMemory:
    def __init__(self, capacity=4):
        self.base_capacity = capacity
        self.capacity = capacity
        self.trace = []
    def record(self, prev, rel, cur, note=""):
        self.trace.append({"from": prev, "rel": rel, "to": cur, "note": note})


class CognitiveAgent:
    def __init__(self, memory, capacity=4):
        self.mem = memory
        self.wm = WorkingMemory(capacity)
        self.graph = ThoughtGraph()
        for src, es in memory.edges.items():
            for e in es:
                self.graph.add(src, e.dst, e.rel, e.weight)
        self.emotion = EmotionState()
        self.emotion_module = EmotionModule()
        self.new_memories = []

    # ---------- 检索：加入情绪一致性偏向 ----------
    def retrieve(self, cue, topk=3):
        act = self.mem.spread([cue], steps=3, decay=0.65)
        biased = self.emotion_module.retrieval_bias(
            act, self.emotion, self.mem.node_emotions()
        )
        return sorted(biased.items(), key=lambda x: -x[1])[:topk]

    # ---------- 整合思考：检索 → 情绪调制 → 推理 → 调节 ----------
    def think_with_emotion(self, start, goal,
                           event_emotions=None, goal_progress_map=None,
                           max_steps=8, regulate_after=None):
        event_emotions = event_emotions or {}
        goal_progress_map = goal_progress_map or {}
        path, cur = [start], start
        self.wm.trace = []

        for _ in range(max_steps):
            if cur == goal:
                break

            # ① 情绪评估：当前节点事件 + 目标进展
            ev = event_emotions.get(cur, (0.0, 0.0))
            gp = goal_progress_map.get(cur, 0.0)
            self.emotion = self.emotion_module.appraise(ev, gp, self.emotion)

            # ② 工作记忆容量受情绪影响
            self.wm.capacity = self.emotion_module.wm_capacity_penalty(
                self.emotion, self.wm.base_capacity
            )

            # ③ 检索（情绪一致性偏向）
            retrieved = self.retrieve(cur, topk=self.wm.capacity)
            rd = dict(retrieved)

            # ④ 推理候选：图邻居 + 记忆激活 + 情绪调制
            cands = self.graph.neighbors(cur)
            scored = []
            for nxt, rel, w in cands:
                s = w * (2 if rel in ("causal", "temporal", "implies") else 1)
                s += rd.get(nxt, 0)
                if nxt == goal:
                    s += 10
                scored.append((nxt, s, rel))

            if not scored:
                self.wm.record(cur, "dead_end", None, "无可用后继")
                break

            # ⑤ 情绪对候选加权（威胁/奖赏/加工模式）
            biased = self.emotion_module.reasoning_bias(
                scored, self.emotion, self.mem.node_emotions()
            )
            biased.sort(key=lambda x: -x[1])
            chosen, _, rel = biased[0]

            self.wm.record(cur, rel, chosen,
                           f"emo={self.emotion} mode={self.emotion_module.mode_switch(self.emotion)} "
                           f"wm_cap={self.wm.capacity} retrieved={retrieved}")
            path.append(chosen)
            cur = chosen

            # ⑥ 情绪调节（可选）
            if regulate_after and cur in regulate_after:
                self.emotion = self.emotion_module.regulate(
                    self.emotion, regulate_after[cur]
                )
                self.wm.record(cur, "regulate", None, f"→ {self.emotion}")

            # ⑦ 自然衰减
            self.emotion.decay(rate=0.08)

        # ⑧ 写回 + 情绪增强巩固
        self.learn_from_thought(path)
        return path

    def learn_from_thought(self, path, name=None):
        name = name or f"thought_{len(self.new_memories)}"
        self.mem.bind_episode(name, path)
        # 情绪唤醒增强巩固
        lr = self.emotion_module.consolidation_gain(self.emotion)
        self.mem.replay(name, cycles=2, lr=lr)
        for a, b in zip(path, path[1:]):
            self.graph.add(a, b, "inferred", 0.8)
            self.mem.add_edge(a, b, "inferred", 0.8, bidirectional=False)
        self.new_memories.append(name)
        return name
```

```python
    nodes = [
        ("起床",   "起床",   ( 0.0, 0.2)),
```

```
【新情景】 ['起床', '下雨', '带伞', '不迟到', '不被批评']
【带伞→不迟到 权重】 1.1...（被情绪唤醒增强）

============================================================
情绪一致性提取对比
============================================================
正情绪下 线索=下雨 → [('带伞', ...), ('下雨', ...), ...]
负情绪下 线索=下雨 → [('忘带伞', ...), ('迟到', ...), ...]
```

> 关键现象：**正情绪时检索偏向正性/奖赏节点（带伞），负情绪时偏向负性/威胁节点（忘带伞、迟到）**。这就是情绪一致性提取在代码中的体现。

## 6. 机制—代码对照表

| 人脑机制 | 对应代码 | 作用 |
|---|---|---|
| 效价—唤醒二维情绪 | `EmotionState(valence, arousal)` | 情绪状态表示 |
| 目标进展评估 | `appraise(event_emotion, goal_progress, ...)` | 事件+目标→情绪变化 |
| 情绪增强巩固 | `consolidation_gain()` → `replay(lr=...)` | 高唤醒记忆更强 |
| 情绪一致性提取 | `retrieval_bias()` | 同效价记忆优先 |
| 情绪作显著性信号 | `arousal_gain` / `salience` | 高唤醒整体激活增强 |
| 威胁偏向 | `reasoning_bias()` 负效价分支 | 焦虑时威胁候选加权 |
| 奖赏偏向 | `reasoning_bias()` 正效价分支 | 积极时奖赏候选加权 |
| 加工模式切换 | `mode_switch()` | 积极→启发式；消极→分析 |
| 工作记忆占用 | `wm_capacity_penalty()` | 焦虑降低有效容量 |
| 情绪调节—重评 | `regulate("reappraise")` | 降低唤醒与负效价 |
| 情绪调节—抑制 | `regulate("suppress")` | 压低强度 |
| 情绪调节—转移 | `regulate("distract")` | 快速降唤醒 |
| 情绪自然衰减 | `EmotionState.decay()` | 回落基线 |
| 预期情绪/价值 | `goal_progress_map` + 候选加分 | 目标情绪引导选择 |

## 7. 与前文的衔接

情绪模块不是独立附加，而是**嵌入前文三条链的每一环**：

| 前文模块 | 情绪接入点 | 效果 |
|---|---|---|
| **记忆链**（第一部分） | 节点带 `emotion` 标记；`retrieval_bias`；`consolidation_gain` | 情绪标记记忆更易提取、更易巩固 |
| **思维链**（第二部分） | `reasoning_bias`；`mode_switch`；`wm_capacity_penalty` | 情绪改变候选权重与加工策略 |
| **相互调用**（第三部分） | `appraise` 在每步评估；`regulate` 在关键节点调节；写回时情绪增强 | 检索—推理—情绪—写回形成闭环 |

### 完整认知回路（加入情绪后）

```
事件/线索
   │
   ▼
┌─────────────┐   情绪评估     ┌─────────────┐
│  记忆网络    │◄──────────────│  情绪模块    │
│ 编码/提取    │  一致性偏向    │ 效价×唤醒    │
└──────┬──────┘                └──────┬──────┘
       │ 激活                          │ 调制
       ▼                              ▼
┌─────────────┐   候选加权     ┌─────────────┐
│  工作记忆    │◄──────────────│  思维链      │
│ 容量受情绪影响│  威胁/奖赏偏向 │ 模式切换     │
└──────┬──────┘                └──────┬──────┘
       │                              │
       ▼                              ▼
┌─────────────┐   情绪增强     ┌─────────────┐
│  写回/巩固   │◄──────────────│  情绪调节    │
│ 新情景+情绪  │  重评/抑制/衰减 │ 回落基线     │
└─────────────┘                └─────────────┘
```

**一句话总结：**  
> 情绪是认知系统的**价值权重层**：它给记忆打显著性标签、给思维候选加权、给决策提供预期价值，并受前额叶调节而回落。把它接入后，`CognitiveAgent` 才从“冷认知”变成“有动机、有偏向、会调节”的完整代理。
